DETECT — prompt length suppresses confidence

GroundingDINO scores drop with query length (30-term prompt: 5 paintings at 0.35–0.37; 3-term: 21 at 0.37–0.48). Fix adopted: batched vocab (6 prompts of ~5 terms, synonyms in different batches, cross-batch NMS). Floor at 0.20 everywhere — permissive sensing, aggressive verification. Open: batch composition effects (a few strong classes softened slightly).

COMPOSE+LOOP — semantic ⇄ physical, anchors first

The last stage is a LOOP over two SUB-STAGES, each a chain of modules. 3.1 SEMANTIC decides WHAT (S1 supported_by → S2 consistency → PH1 snap (physical evidence, drawn in run order) → S3 propose edits → S4 screening → S5 shopping = the cast list; add / delete / replace edits re-enter at screening, where S3's proposals also land); 3.2 PHYSICAL decides WHERE at mesh time (PH2 collide gate → PH3 box surgery — deterministic, the LLM never gets to violate physics; the suspect-box work orders land in PH3).
